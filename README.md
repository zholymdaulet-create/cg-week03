## Тапсырма ауыстырғыштары (файл басында)
```cpp
const bool TASK1_INVERT_COLORS = true;   // 1-тапсырма
const bool TASK2_SAME_COLOR    = false;  // 2-тапсырма
const bool TASK3_FLIP_Y        = true;   // 3-тапсырма
const bool TASK4_BROKEN_SHADER = false;  // 4-тапсырма (тапсырарда false!)
```
Қорғауда біреуін `true`/`false` етіп, қайта құрастырып көрсетесің.

## Не жасалды
- `makeShader()` — компиляция (`glGetShaderiv` + `GL_COMPILE_STATUS`) және линковка (`glGetProgramiv` + `GL_LINK_STATUS`) тексерулерімен, қате болса логты шығарады.
- Вершина = 6 float (позиция + түс), `STRIDE = 6 * sizeof(float)` екі атрибутта да, түс offset-і `(void*)(3 * sizeof(float))`.
1. `1.0 - vColor` — түстер төңкерілген.
2. Үш вершинаға бірдей түс — градиент жоғалады.
3. `aPos.y * -1.0` — үшбұрыш төңкеріледі.
4. Әдейі қате (`vec5` + `;` жоқ) — хабарлама төменде.

## 4-тапсырма: қате хабарламасы
> ⚠️ Бұл менің тест машинамдағы (Mesa) мәтін. Өз компьютеріңде `TASK4_BROKEN_SHADER = true` етіп іске қос та, **өз** хабарламаңның скриншотын/мәтінін осында қой — драйверге қарай формат өзгеше болады (NVIDIA/AMD/Intel).

```
FRAGMENT shader compile error:
0:7(7): error: syntax error, unexpected NEW_IDENTIFIER, expecting ',' or ';'

Program link error:
error: linking with uncompiled/unspecialized shader
```
Оқу: `0:7(7)` — 0-ші шейдер-жол, **7-жол**, 7-баған. Жол шейдер мәтінінің басынан саналады (`R"(` кейінгі бос жол — 1-жол, `#version` — 2-жол), C++ файлының жол нөмірі емес. 7-жол — `vec5 c = ...`: `vec5` деген тип жоқ, сондықтан компилятор оны белгісіз атау деп қабылдады. Компиляция құлағандықтан, линковка да құлады.

## Қорғауға жауаптар
**Градиент қайда кетті? Оны кім есептейді?** Градиентті **растеризатор** (vertex пен fragment шейдер арасындағы бекітілген кезең) есептейді: `out vColor` мәндерін үшбұрыш ішіндегі әр пиксельге барицентрлік координаталармен интерполяциялайды. Үш вершина бірдей түсті болса — интерполяция нәтижесі де бірдей, градиент жоқ.

**Неге gl_Position экрандағы орынды анықтайды?** Бұл GLSL-дің **кірістірілген (built-in)** шығысы — конвейер позицияны тек осыдан оқиды (clip space → perspective divide → NDC → viewport → пиксель). Басқа айнымалыны (мысалы `vColor`) өзгертсең — ол тек fragment шейдерге интерполяцияланып барады, орынға әсер етпейді.
